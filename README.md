# WedLink 智慧婚禮整合平台

繁體中文婚禮形象與免費方案試算網站。使用靜態 HTML、CSS、JavaScript，不需付費 API 或後端伺服器。

## 網站功能

- 9 組下拉選單：婚宴飯店、新秘、美甲、美髮、平面攝影、動態錄影、SDE、婚紗包套、毛片與精修
- 桌數乘算、婚宴 10% 服務費、精修張數加購與即時總計
- 分類小計、預算上限與超支提示
- CSV 預算表下載、籌備清單及瀏覽器本機紀錄
- 手機與桌機響應式版面

價格以提供的 WedLink_Wedding_Cost_Database.docx 為固定參考資料，實際報價以商家為準。網站沒有真實預訂、付款、帳號註冊或對外詢價功能。商業模式畫布與知識挑戰已依需求移除。

## 發布

GitHub Pages 使用本儲存庫 main 分支的根目錄。所有資源採相對路徑，可放在 GitHub 專案網站的子路徑。原始文件未上傳。
